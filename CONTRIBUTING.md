# Contributing

Small, thoughtful improvements are welcome. Keep the first postcard simple.

- Preserve local-only audio processing and self-contained exports.
- Add both English and Chinese copy for UI changes.
- Keep controls keyboard-accessible and layouts usable at narrow widths.
- Preserve literal user text. Do not inject it into script, styles or unescaped HTML.
- Audio changes should include a focused regression test with generated fixtures.
- Run npm test and npm run build, then check the editor and an exported card in a browser.
- Describe the concrete issue and behavior change in a pull request.

Do not attach private recordings or personal postcards to public issues. Use generated audio and fictional text to reproduce a bug.
